What it does

One CLI, five agent formats, zero runtime dependencies in the output.

📦

Self-contained output

Every replay is a single HTML file with the transcript embedded (zlib + base64). Open it offline or host it anywhere.

🤖

Five agent formats

Reads Claude Code, Cursor, Codex CLI, Pi, and exported OpenCode sessions — auto-detecting the format for each file.

🔒

Secret redaction

Optional regex-based redaction strips API keys and tokens from the transcript before it gets embedded.

🔁

Round-trips back

ai-replay extract pulls the original turns back out of any generated HTML as clean JSONL.

🎨

Themeable player

Ships with multiple color themes (dark-knight, tokyo-night, monokai, dracula, and more) injected as CSS variables.

⌨️

Interactive picker

Run ai-replay with no arguments for a TUI that discovers and lists your recent sessions across agents.

Get started in seconds

Install, point it at a session, open the result.

$ ai-replay session.jsonl -o replay.html

Or just run ai-replay to pick a recent session interactively. Claude Code, Cursor, Codex CLI, and Pi sessions are discovered automatically; OpenCode needs a one-off export. See the full README for export, redaction, and serving options.
